Self Attention만을 활용하여 문맥을 학습하는 신경망 기반의 NLP 모델.

구분내용
아키텍처(인코더/디코더) Self-Attention, Multi-Head Attention, FFN, Layer Nomalization, Positional Encoding (디코더) E-D Attention, Masked Self-Attention, Softmax

최적화 기법가. Attention 구조 최적화 - Sparse Attention : 전체 토큰이 아니라 일부 토큰에만 Attention을 수행하여 O(n²) 비용 절감 - Local Attention : 일정 윈도우 내 인접 토큰 중심으로 Attention 수행 - Sliding Window Attention : 긴 시퀀스를 구간별로 나누어 이동창 방식으로 처리 - Linear Attention : Kernel Trick을 활용해 Attention 연산을 O(n)에 가깝게 근사 - FlashAttention : Attention 계산 시 메모리 접근을 줄여 GPU HBM I/O 병목 완화 - Multi-Query Attention : 여러 Query Head가 하나의 Key·Value를 공유하여 KV Cache 크기 절감 - Grouped-Query Attention : MHA와 MQA의 절충 방식으로 성능과 메모리 효율 균형 확보 나. 모델 구조 최적화 - Low-Rank Approximation : 큰 행렬을 저랭크 행렬로 분해하여 파라미터와 연산량 절감 - Pruning : 중요도가 낮은 Head, Neuron, Weight를 제거하여 모델 경량화 - Quantization : FP16, INT8, INT4 등 저정밀 연산으로 메모리와 연산비용 감소 - Knowledge Distillation : 대형 Teacher 모델의 지식을 소형 Student 모델에 전달 - MoE : 모든 파라미터를 사용하지 않고 일부 Expert만 활성화하여 연산량 절감 - Parameter Sharing : 레이어 간 파라미터를 공유해 모델 크기 감소 다. 추론·운영 최적화 - KV Cache : 이전 토큰의 Key·Value를 재사용하여 반복계산 제거 - PagedAttention : KV Cache를 페이지 단위로 관리해 메모리 단편화와 낭비 감소 - Dynamic Batching : 요청을 동적으로 묶어 GPU 처리량 향상 - Continuous Batching : 생성 중인 요청과 신규 요청을 함께 처리하여 대기시간 감소 - Speculative Decoding : 작은 Draft Model이 후보 토큰을 생성하고 큰 모델이 검증하여 속도 향상 - Prompt Cache : 반복되는 시스템 프롬프트와 공통 Prefix를 캐시하여 TTFT 단축 - Model Routing : 질의 난이도에 따라 SLM, 중형모델, 대형모델을 동적으로 선택
