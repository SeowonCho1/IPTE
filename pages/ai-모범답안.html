문항 1. 교차검증(Cross-Validation)

일반화 성능Out-of-SampleK-FoldStratifiedData LeakageNested CV

Ⅰ. 일반화 성능 검증을 위한 반복 학습·평가 기법, 교차검증의 정의

  • 교차검증(CV): 원본 데이터를 학습·검증·테스트로 분할하고 구성을 달리하며 반복 학습·평가하여 일반화 성능(Generalization)을 추정하는 기법(Out-of-Sample Testing)
  • Hold-out: Train/Val/Test 1회 분할, 단순·고속, 데이터 활용률 낮음
  • K-Fold: K등분, K-1 학습·1 검증을 K회 반복 후 평균 성능 산출
  • Stratified K-Fold: 클래스 비율 유지 분할, 불균형 데이터 대응
  • LOO-CV: N-1 학습·1 검증을 N회, 활용 극대화·연산 비용 최대

Ⅱ. K-Fold 교차검증 메커니즘 및 분할 구조

          Fold1   Fold2   Fold3  …  FoldK
Iter 1  [ Test ][Train ][Train ]…[Train ]
Iter 2  [Train ][ Test ][Train ]…[Train ]
  ⋮          ⋮       ⋮       ⋮         ⋮
Iter K  [Train ][Train ][Train ]…[ Test ]
─────────────────────────────────────────
각 Fold가 1회씩 Test → K개 점수 평균 = CV Score
σ(표준편차)로 안정성(분산)까지 함께 보고
K 선택의 Bias-Variance 관점
K 작음 → Train 적음 → Bias↑ (과소평가)
K 큼   → Fold 간 중복↑ → Variance↑·연산량↑
실무 표준: K = 5 또는 10 (경험적 최적 trade-off)
시계열: TimeSeriesSplit(과거 Train·미래 Test) — 무작위 분할 금지
[간글] 교차검증은 분할·평가 구조이므로, 과적합·편향·분산 Trade-off 관점의 한계와 데이터 누수(Leakage) 방지가 핵심 보완점이다.

Ⅲ. 교차검증 한계 및 실무 적용 방안

  • 한계: K-Fold 연산 비용 증가, Hold-out 데이터 부족 시 불안정
  • 불균형: Stratified Split·Stratified K-Fold 필수
  • 시계열: 무작위 분할 금지, 시간순 분할(Walk-forward) 적용
  • 실무: Stacking·Blending 메타모델 학습 시 K-Fold OOF 예측값 활용
  • 과적합 완화: CV Score 기반 Early Stopping·하이퍼파라미터 튜닝
＋ 가점 보강 추가변별력 확보 요소
기법핵심적용 상황
Nested CV외부 Loop=성능추정 / 내부 Loop=튜닝하이퍼파라미터 튜닝 시 낙관 편향·누수 방지
Group K-Fold같은 그룹(환자·사용자)은 한 Fold에만중복 개체 누수 방지(의료·세션)
Repeated K-Fold분할을 시드 바꿔 반복 평균소규모 데이터 추정 안정화
TimeSeriesSplit시간순 누적 분할수요예측·금융·로그
데이터 누수(Data Leakage) 방지 — 단골 감점 포인트 정규화·결측대치·인코딩·오버샘플링(SMOTE)은 반드시 Fold 내부(Train에 fit → Val에 transform)에서 수행. 전체 데이터에 먼저 적용하면 검증 점수가 부풀려진다. scikit-learn Pipeline + cross_val_score로 구조적 차단.
아키텍트 제언 Train/Val/Test 역할 분리, Seed·Fold 고정으로 재현성 확보, CI에서 CV Score 회귀 테스트, 데이터 버전(DVC)·실험 추적(MLflow)으로 평가 신뢰성 관리.
채점 포인트(반드시 노출할 키워드)
  • 일반화·Out-of-Sample / K=5·10 / Bias-Variance와 K의 관계
  • Stratified(불균형)·TimeSeriesSplit(시계열)·Group(누수)
  • 전처리는 Fold 내부 — Data Leakage 방지 / Nested CV

문항 2. 차원의 저주(Curse of Dimensionality)

Sparsity거리 집중Hughes 현상PCAManifoldEmbedding

Ⅰ. 고차원 공간의 데이터 희소·거리 왜곡 현상, 차원의 저주 정의

  • 차원의 저주: 피처(차원) 수 증가 시 데이터 밀도가 급감하고 거리가 수렴하여 학습이 어려워지는 현상
  • 고차원에서 모든 점 간 거리가 유사해지는 거리 집중(Distance Concentration)
  • 샘플 수 대비 차원 증가 → 표본 희소(Sparsity)·과적합 위험 증대
  • Grid Search 시 조합 폭발 → 하이퍼파라미터·탐색 비용 급증
  • 특징: 차원↑ → 일반화 성능↓, 연산·저장 비용↑

Ⅱ. 차원의 저주 발생 메커니즘

[저차원] ●─●─●        밀집·거리 구분 용이
[고차원] ●  ·  ●  ·  ●  희소·거리 유사(구분 곤란)

원인① 표본 밀도 감소(Sparsity)   ② 거리 척도 무의미화
원인③ 과적합·분산 증가           ④ 탐색 공간 기하급수 확대
왜 거리가 무의미해지는가 (정량적 직관) 추가
① 단위 초입방체 부피의 99%가 표면(껍질)에 집중 → 중심 데이터 희박
② d→∞ 일 때  (Dmax − Dmin) / Dmin → 0
   ⇒ 최근접·최원접 거리 차이 소멸 → KNN·군집 무력화
③ 차원 d, 일정 밀도 유지에 필요한 표본 ∝ 지수적 증가
[간글] 발생 원인이 구조적이므로, 차원 축소·규제·효율 탐색과 함께, 실제 데이터가 저차원 다양체에 분포한다는 Manifold 가설을 활용한 대응이 필요하다.

Ⅲ. 차원의 저주 해결방안 및 실무 제언

전략기법비고
차원축소PCA(선형·분산보존), Autoencoder/VAE(비선형 잠재표현)특징 압축
특징선택상관·정보이득·Lasso(L1)·RFE불필요 변수 제거
규제화L1/L2·Dropout·Early Stopping과적합 억제
탐색효율Grid → Random → Bayesian Opt조합 폭발 완화
데이터표본 확보·합성(SMOTE/증강)밀도 보강
＋ 가점 보강 추가심화 키워드·최신 기법
  • Hughes 현상(Peaking Phenomenon): 표본 고정 시 차원 증가에 따라 성능이 정점 후 하락 → "특징은 많을수록 좋다"는 오해 반박
  • Manifold 가설: 고차원 데이터도 실제로는 저차원 다양체에 분포 → t-SNE·UMAP(시각화), Isomap(비선형 축소)
  • Embedding: 희소 고차원(원-핫)을 밀집 저차원 벡터로(Word2Vec·딥러닝 임베딩) → NLP·추천의 표준 해법
  • Feature Hashing·Random Projection(Johnson–Lindenstrauss): 거리 보존하며 저차원 사상
아키텍트 제언 모델링 전 차원 d : 표본 N 비율을 점검(경험칙 N ≫ d), 도메인 지식 기반 특징선택과 통계적 축소를 병행, 임베딩·정규화로 거리 기반 모델의 안정성 확보.
채점 포인트
  • Sparsity·거리 집중·(Dmax−Dmin)/Dmin→0 / Hughes 현상
  • PCA·AE / Lasso·특징선택 / Bayesian 탐색
  • Manifold 가설·Embedding(차별화 키워드)

문항 3. CNN vs GAN 비교

Convolution지역 특징적대학습MinimaxMode CollapseDiffusion

Ⅰ. 공간 특징 학습 vs 적대적 생성 구조, CNN·GAN 개념

  • CNN: 이미지 등 격자 데이터의 지역 특징을 학습하는 신경망. Conv→Pool→FC, Kernel·Stride·Padding·Feature Map. 지역연결·가중치 공유로 파라미터↓
  • GAN: Generator·Discriminator 적대학습 기반 생성 모델. Generator(노이즈 z→합성), Discriminator(진·가 판별)
  • 관점: CNN=판별(Discriminative), GAN=생성(Generative)

Ⅱ. CNN·GAN 아키텍처 비교

[CNN] Input → Conv → ReLU → Pool → … → Flatten → FC → Softmax

[GAN]  z(noise) → Generator → Fake ┐
                                    ├→ Discriminator → Real/Fake
        Real Data ─────────────────┘   (G·D 번갈아 학습)
핵심 수식 추가

GAN  : min max  E[log D(x)] + E[log(1−D(G(z)))]   (Minimax, Nash 균형)
        G    D

Ⅲ. 한계 및 실무 적용

  • CNN 한계: 대량 Label·GPU 필요, 위치·회전 변환에 Pooling 의존(→ ViT/Attention 보완)
  • GAN 한계: Mode Collapse(다양성 붕괴), 학습 불안정, 윤리·법적 리스크
  • 상호활용: GAN Discriminator에 CNN 백본(Xception 등), 딥페이크 탐지 CNN
  • 아키텍트: 목적별 아키텍처 분리, 생성 AI 거버넌스·탐지(워터마킹·C2PA) 체계 구축

문항 4. 지도 학습 vs 비지도 학습 비교

Label분류·회귀군집·축소반지도자기지도(SSL)전이학습

Ⅰ. Label 유무에 따른 학습 패러다임

  • ML: 명시적 프로그래밍 없이 데이터로부터 패턴을 학습
  • 지도학습: 입력-정답(Label) 쌍으로 학습 → 예측(분류·회귀)
  • 비지도학습: Label 없이 구조·패턴 발견 → 탐색(군집·축소·연관)
  • 보조: 강화학습(Reward 기반 정책), 반지도·자기지도(하이브리드)

Ⅱ. 지도·비지도 학습 구조 비교

Ⅲ. 실무 선택 기준 및 아키텍트 제언

  • 지도: 목표 변수 명확·Label 확보 가능(사기탐지·가격예측)
  • 비지도: 고객세분·이상탐지·차원축소·장바구니 분석
  • 반지도: 소량 Label + 대량 Unlabeled(의료·제조)
  • 전이학습: 사전학습 모델 Fine-tuning으로 Label 비용 절감

문항 5. 혼동행렬(Confusion Matrix) 및 성능평가

Precision/RecallF1ROC-AUCPR-AUCThresholdCost Matrix

Ⅰ. 분류 결과 오분류 구조 표현, 혼동행렬 정의

  • 혼동행렬: 실제(Actual)×예측(Predicted) 교차표 — TP(정탐)·TN(정음)·FP(오탐)·FN(미탐)
  • 분류 모델 성능지표 산출의 기초 행렬, 이진·다중 분류 모두 확장
  • 불균형 데이터에서 Accuracy 단독 사용은 부적절(다수 클래스 편향)

Ⅱ. 혼동행렬 구조 및 성능지표 산식

              예측 Positive   예측 Negative
실제 Positive |     TP      |     FN      |
실제 Negative |     FP      |     TN      |
핵심 지표
Precision = TP/(TP+FP)        정밀도·오탐 억제
Recall(TPR) = TP/(TP+FN)      재현율·미탐 억제
F1 = 2·P·R/(P+R)              P·R 조화평균
Accuracy = (TP+TN)/Total      균형 데이터 한정
[간글] 기본 지표 산출 후, 데이터 특성과 비즈니스 비용(Cost)에 따라 ROC-AUC·PR 곡선·임계값 조정 등 보완 평가가 필요하다.

Ⅲ. 불균형 데이터 대응 및 실무 제언

  • 불균형: Recall·F1·PR-AUC 우선, Threshold 조정
  • 의료·사기: FN 비용 큼 → Recall·민감도 중시
  • 스팸·추천: FP 비용 큼 → Precision 중시
  • ROC: TPR vs FPR·AUC(균형) / PR Curve: P vs R(희귀 Positive)
＋ 가점 보강 추가확장 지표·다중분류
확장 지표
Specificity(TNR) = TN/(TN+FP)      FPR = FP/(FP+TN)
Balanced Acc = (TPR+TNR)/2          불균형 보정 정확도
MCC = (TP·TN − FP·FN)/√(…)          불균형에 강건(−1~1)
Cohen's Kappa                        우연 일치 보정 일치도
다중분류 평균의미적합
Macro클래스별 단순 평균소수 클래스 동등 중시
Micro전체 TP/FP/FN 합산샘플 단위 전체 성능
Weighted클래스 빈도 가중분포 반영
실무 핵심 ① 불균형 심하면 ROC-AUC는 낙관적 → PR-AUC가 더 정직. ② Threshold Moving·Cost-Sensitive Learning으로 운영점 결정. ③ 확률 신뢰도는 Calibration(Platt/Isotonic)으로 보정.
아키텍트 제언 비즈니스 Cost Matrix(FP·FN 비용)를 사전 합의하고, 지표·임계값·재학습 주기를 SLA로 명문화, 운영 중 분포 변화(Drift) 모니터링.
채점 포인트

  • 불균형 → PR-AUC·Threshold·Cost / 도메인별(FN vs FP) 비용
  • MCC·Balanced Acc·Macro/Micro·Calibration(차별화)

문항 6. ML 모델 — 과적합·과소적합, 파라미터·하이퍼파라미터, 최적화

일반화Bias-Variance규제하이퍼파라미터Bayesian OptMLOps

Ⅰ. 데이터 기반 예측 모델링과 일반화 과제 (개요)

  • ML 모델: 데이터로부터 패턴을 학습·예측·분류하는 구조(Training→Model→Inference)
  • 핵심 과제: Train 성능과 Test 성능 간 일반화 격차 최소화
  • Bias-Variance Trade-off가 모델 복잡도·성능을 좌우
  • 실무: 데이터 품질·모델 선택·검증·튜닝의 통합 설계 필요
