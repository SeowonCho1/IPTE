완완벽한 테스팅 불가능모든 입력과 경로 테스트는 자원 한계로 불가능, 우선순위 기반 접근 필요
초초기 테스팅 시작개발 초기부터 리뷰와 테스트 설계 수행 시 수정 비용 감소
집결함 집중소수 모듈에 다수 결함 집중, 위험 모듈 중심 테스트 필요
살살충제 패러독스동일 테스트 반복 시 결함 탐지율 감소, 테스트 케이스 개선 필요
정정황 의존성도메인, 위험, 환경에 따라 테스트 전략 차별화 필요
오오류 부재의 궤변결함이 적어도 사용자 요구를 만족하지 못하면 품질 확보 실패
