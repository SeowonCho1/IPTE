5.2.2 DORA Metrics (Google)

지표질문개선 방향연관 CALMS
Deployment Frequency얼마나 자주 배포하는가빈도 ↑Automation
Lead Time for Changes변경이 운영까지 얼마나 걸리는가시간 ↓Lean, Automation
Time to Restore (MTTR)장애 후 얼마나 빨리 복구하는가복구 ↓Sharing, Measurement
Change Failure Rate배포 중 실패·롤백 비율은실패율 ↓Culture, Automation
답안 문장 DevOps는 CALMS 원칙(문화·자동화·린·측정·공유)으로 개발과 운영을 통합하고, Google DORA 4 Metrics(배포 빈도, 변경 리드타임, 복구 시간, 변경 실패율)로 소프트웨어 전달 성과를 정량 평가·개선한다.

5.2.3 IaC (Infrastructure as Code)

정의: 서버, 네트워크, 스토리지, 클라우드 리소스 등 인프라 구성을 코드로 정의·관리하여 수동 설정 대신 자동화·버전관리·재현 가능한 환경을 만드는 DevOps 실천 방법이다.

흐름/도식

[인프라 요구] → [IaC 코드 작성] → [Git 버전관리·코드리뷰] → [CI/CD Plan/Apply] → [환경 프로비저닝] → [Drift 모니터링]
                ↑ 선언적 정의 · 멱등성(Idempotency) · 재현성 · 감사 추적(Audit Trail)
구분내용답안 키워드
핵심 개념인프라를 소프트웨어처럼 코드로 관리Infrastructure as Code
선언적(Declarative)원하는 목표 상태를 기술, 도구가 현재→목표로 수렴Terraform, CloudFormation
절차적(Imperative)설정·배포 단계(명령)를 순서대로 실행Ansible Playbook, Shell
멱등성동일 코드를 여러 번 적용해도 결과 상태가 일관Idempotency
버전관리인프라 변경 이력·롤백·코드 리뷰 가능Git, Pull Request
GitOpsGit을 단일 진실 공급원(SSOT), PR 승인 후 자동 반영Argo CD, Flux
Drift Detection실제 인프라와 코드 정의 간 차이(드리프트) 감지·교정Configuration Drift
DevOps 연계CALMS의 Automation — CI/CD와 함께 앱·인프라 동시 배포Pipeline as Code
답안 문장 IaC(Infrastructure as Code)는 인프라를 코드로 정의·버전관리·자동 프로비저닝하여 환경 재현성·일관성·감사 추적을 확보하고, CI/CD·GitOps와 결합해 DevOps Automation을 실현한다.

13.4 ISO 26262과 ASIL

답안 문장 ISO 26262는 IEC 61508의 기능안전 개념을 자동차 분야에 적용하여 차량 전기, 전자 시스템의 위험을 분석하고, ASIL 등급에 따라 안전 요구사항, 설계, 구현, 검증 수준을 차등 적용하는 자동차 기능안전 표준이다.

ASIL 결정 지표: 심노제
심각도 Severity, 노출도 Exposure, 제어가능성 Controllability

Severity사고 발생 시 피해 심각도부상, 사망, 재산 피해

도식: 암기 카드 활용 루틴

[질문 보기] → [두음 떠올리기] → [한 줄 확장] → [도식으로 복원] → [답안 문장 작성]

의미: 카드는 정답 확인용이 아니라, 두음을 답안 문장으로 바꾸는 훈련용

  • Q1. SDLC 단계 암기?

- 정답: 타요설개테운폐: 타당성검토, 요구분석, 설계, 개발, 테스트, 운영 및 유지보수, 폐기

  • Q2. ISO/IEC 9126 품질특성?

- 정답: 기신사효유이: 기능성, 신뢰성, 사용성, 효율성, 유지보수성, 이식성

  • Q3. SQuaRE 구성 암기?

- 정답: 요모관측평확: 요구사항, 모델, 관리, 측정, 평가, 확장

  • Q4. ASIL 결정 지표?

- 정답: 심노제: Severity 심각도, Exposure 노출도, Controllability 제어가능성

  • Q5. 모듈화의 좋은 방향?

- 정답: 높은 응집도, 낮은 결합도

  • Q6. CMMI 성숙도 5단계?

- 정답: 초관정관최: 초기, 관리, 정의, 정량관리, 최적화

  • Q7. DevSecOps 보안 삽입 위치?

- 정답: 계획, 개발, 빌드, 테스트, 배포, 운영 전 단계에 보안 자동화 적용

  • Q8. Product Line 3대 활동?

- 정답: Domain 공학, Application 공학, Management
